## 🚀 Projetos em destaque

### 🦷 Devs do Bem | Challenge Turma do Bem
Meu principal projeto: uma plataforma web para a **ONG Turma do Bem** (que oferece atendimento odontológico a jovens em situação de vulnerabilidade), desenvolvida em equipe de quatro pessoas. A ideia é centralizar em um só lugar o que hoje fica espalhado, como doação, informação, gestão e recebimento de mensagens, e usar uma **IA com personalidade própria** (o assistente do projeto tem o ícone de um dente) conectada ao banco de dados, para que qualquer informação possa ser obtida apenas pedindo a ela.

O desafio atravessa várias disciplinas, e em cada uma entregamos uma parte:

- **Front-End:** site estático com 6 páginas (início, sobre, FAQ, contato, quem somos e um protótipo da inscrição em etapas), feito só com HTML e CSS, sem frameworks e sem JavaScript por enquanto, a pretensão é ir implementando aos poucos, novas funcionalidades, e tecnologias, conforme apreendemos.
- **Java (DDD):** modelagem do sistema em UML com 10 classes e implementação em Java no IntelliJ IDEA.
- **Minha parte:** atuo em Design e Desenvolvimento e divido com o Pablo a responsabilidade pelas disciplinas de Front-End, Java e Inteligência Artificial.

🛠️ Tecnologias: HTML5, CSS3, Java, UML, Git e GitHub

- 📂 [Ver o repositório](https://github.com/PabloAckillys/project_tdb_print1)

### 🦷 SITB, Sistema Integrado Turma do Bem
Projeto em equipe da disciplina de Domain Driven Design Using Java. Na primeira etapa, modelamos o sistema em um diagrama UML com 10 classes (como Beneficiário, Dentista Voluntário, Doador, Campanha e Doação). Na segunda, implementamos essas classes em Java no IntelliJ IDEA, organizadas em packages e com uma classe principal que recebe os dados por janelas `JOptionPane`.

- 🛠️ Tecnologias: Java, UML e IntelliJ IDEA
